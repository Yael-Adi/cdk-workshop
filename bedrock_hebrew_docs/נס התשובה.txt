# נס התשובה

נֵס הַתְשׁוּבָה

ממוזער|דגלי קוד האיתות הבינלאומי, 1902
  אחד מדגלי הקוד הבינלאומי לאיתות הנוהג באוניות, אותו מניפים לאחר שהתקבל איתות דגלים מאונייה אחרת או מן החוף, כדי לציין שההודעה הובנה. 
 

גיזרון
  answering pendant. שמו המלא של הדגל הוא "דגל הקוד ונס התשובה".
 האקדמיה ללשון העברית, מילון למונחי הימאות (תש"ל), 1970: answering pennant, code pennant - נס קוד.
