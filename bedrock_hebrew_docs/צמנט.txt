# צמנט

צֶמֶנְט

 אבקה מינרלית שבתגובה כימית עם מים יוצרת מוצק דמוי אבן (מליטה). משמשת בתעשיית הבנייה ליצירת מלט ובטון.
(נקרא גם צמנטום) חומר עשוי סידן אשר מכסה את שורש השן

 גזרון 

 מלטינית, caementum, אבן מנופצת. הגיית העיצור הראשון כ"צ" מושפעת מהגיית הגרמנית את האות c כך.
