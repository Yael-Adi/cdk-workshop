# מפגר

מְפַגֵּר

 נחשל, נשאר מאחור, מאחר, שאינו מתקדם כאחרים.
 המטילים חכו למפגרים מאחור.
  בן אדם שסובל מפיגור שכלי.

גיזרון
 משורש מקראי, צורת בינוני של הפועל פִגֵּר. 

מידע נוסף
 בנובמבר 2016 אישרה מליאת הכנסת בקריאה ראשונה הצעת חוק להחליף את המונח "מפגר" במונח "אדם עם מוגבלות שכלית התפתחותית" (מש"ה) - ראה הודעה באתר הכנסת העשרים, 3 בינואר 2017, לאחר שב-17 ביוני 2012 קיבל שר הרווחה והשירותים החברתיים, משה כחלון, את המלצת הצוות לבדיקת שם חלופי למונח "פיגור שכלי", להחליף באופן רשמי את המונח "פיגור שכלי" במונח "מוגבלות שכלית התפתחותית" - ראה ידיעה.
