# אנרגיה

אֵנֶרְגִּיָּה

היכולת לבצע עבודה, הפעלת כוח לאורך דרך.
 דרושה אנרגיה כדי להרים משא מנקודה נמוכה לנקודה גבוהה, כדי לחמם מים או כל גוף אחר, להסעת רכב, להפקת אור. 
 האנרגיה יכולה להיות גלומה (טמונה, צבורה) באופנים שונים: אנרגיה גרעינית, חשמלית, כימית, פוטנציאלית ועוד.
 אנו משתמשים במקורות אנרגיה כדי לחמם את בתינו (חשמל ודלק), כדי להסיע את רכבינו (דלק), כדי להאיר את הבתים והרחובות (חשמל).

גיזרון
 מיוונית: ενέργεια שבאה מהמילה ενέργον (פעולה, עבודה): εν (פנימי) + έργον (עבודה).
