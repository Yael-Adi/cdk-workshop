# כל דכפין

כָּל דִּכְפִין

 כל מי שרעב.
 כל דכפין מוזמן לבוא לביתי, ואפתח לו שולחן.
  כל מי שרוצה.
 האופניים מונחים בגינה, זמינים לכל דכפין.

גיזרון
  ד+כפין = שֶׁ+רָעֵב: הפועל מופיע באונקלוס כתרגום לעברית רעב ( = ) והשורש גם מופיע בעברית במקרא, ראה כָּפָן 'רָעָב'.
 מקור הביטוי הינו בהגדה של פסח:  - כל מי שרעב יבוא ויאכל, כל מי שצריך יבוא ויעשה את סדר פסח.
