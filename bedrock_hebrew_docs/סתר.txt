# סתר

סָתַר

 ביטל את הקיים שבר את הבנוי.
 
 
  
 ביטל מבנה מסודר קלקל או פיזר את הערוך יפה.
  
 
  אמר דברים מנוגדים, הוכיח כלא נכון.

 אינך יכול לומר כך שכן את סותר את עצמך.
 בנאומו סתר את דברי קודמו.
